# 2026 华东杯 C 题：高波动标的收益率预测

## 项目背景
本项目参加 2026 年华东杯数学建模竞赛 C 题。题目要求针对金融市场中 **30 支高波动标的** 的 **1 分钟 OHLCV K 线数据** 进行建模，预测未来的收益率。

## 任务目标
- **预测标的**：未来 5 分钟收益率、未来 60 分钟收益率  
- **数据特点**：价格已做基准化处理，只有开盘价、最高价、最低价、收盘价、成交量  
- **核心挑战**：在普通行情和极端行情下均需保持较好的预测能力  
- **可选探索**：多市场、多标的联合建模（加分项）

## 提交内容
按照竞赛要求，最终需提交：
- `feature_generation.py`：特征生成脚本  
- `predict.py`：预测脚本  
- `model_params.json` 等模型参数文件  
- 一份完整的论文（分析特征、模型、结果）

评测平台：`http://118.196.107.100:8000`  
仅支持 `scikit-learn`、`LightGBM`、`PyTorch` 三种框架。

## 重要约束
- 所有结果必须可严格复现，需提供训练脚本与随机种子  
- 禁止使用未来函数、外部数据及任何破坏公平性的操作  
- 提交的脚本只能包含与赛题任务直接相关的代码
